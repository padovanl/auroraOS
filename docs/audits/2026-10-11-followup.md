user's push failure and additional everyday file, clipboard, network and settings
flows. Usage instructions are in the Files, Power, Language/Date & Time and Virtual
Machines manual chapters; the generated manual and website are rebuilt from them.

## Bugs fixed

- A stale internal file clipboard could override a newer selection from another
  application. Paste now follows the actual GDK clipboard provider. GTK file lists
  and GNOME's `x-special/gnome-copied-files` format carry copy/cut correctly.
- A failed cut was discarded before its transfer finished. Remaining files now stay
  available; the Retry button preserves the completion handler and clears a
  successful cut. Completing an older move cannot overwrite a newer clipboard.
- A directory could be copied into its own subtree through a symbolic-link alias.
  The worker resolves both paths before starting a recursive transfer.
- A native move could overwrite a file created between destination selection and
  the actual rename. GIO's no-overwrite move is now used, with cancellable copying
  when crossing filesystems.
- Copying a named pipe could block indefinitely. The worker rejects special files
  and uses a nonblocking, no-follow open plus descriptor validation to cover a
  source replaced between inspection and opening.
- A GIO exception during history restoration could leave Undo permanently busy.
  The worker now reports the error and always releases the busy state.
- Interrupted AI downloads discarded useful partial content or retried a complete
  partial file with an invalid range. Complete parts are verified and finalized
  locally; short responses remain resumable. Existing final files are checksum
  verified, and a server ignoring Range cannot bypass the free-space check.
- Independent power-button and lid writes could race on the same logind
  configuration file. The privileged helper serializes those edits with a lock
  in its root-owned runtime directory. A disposable-container check applied
  80 concurrent pairs and preserved both values every time.
- Time, timezone, power-button, lid and charge-limit authorization ran on GTK's
  main thread and failed selections were left visible as though applied. Workers
  now keep GTK responsive, prevent repeated pending requests and restore the
  confirmed value when authorization fails or is cancelled.
- A network backend could omit optional hidden/backup attributes, producing GIO
  critical errors during file filtering and grid rendering. Missing attributes now
  fall back to the filename while explicit backend metadata keeps precedence.
- The grid/list selection gesture intercepted file drags before item-level
  sources could start. A capture source above both views uses the files hit at
  the original press, even when GTK’s rubber-band overlay subsequently covers
  that point. Factory rows keep their identity and read the live list-item
  position, including after garbage collection and model updates. The source
  declines an empty-space press so GTK can still draw a selection rectangle.
- Filename dialogs left their confirmation button active for invalid names.
  The button now follows the live entry validation; bookmark labels use their
  own rules and can contain `/`.
- External COPY|MOVE drag offers were treated as a selected move even with Ctrl
  held. Folder targets now negotiate the modifier action and respect copy-only
  sources. Wayland DND motion events do not carry keyboard modifiers; the target
  reads its seat’s keyboard state and keeps the negotiated action while
  asynchronous payload data arrives.
- Files performed synchronous information requests on network locations. These
  now use cancellable asynchronous GIO calls; an old response or mount completion
  cannot override a later navigation or closed window.

## Missing everyday features added

- **Folder favorites:** Add to Sidebar for selected folders, the current folder or
  an existing place; rename/remove from the favorite's context menu. Removing a
  favorite keeps its files. Standard GTK bookmarks support custom labels, network
  URIs, legacy-file migration and reload/retry on concurrent edits. File monitors
  update all open windows and disconnect when the sidebar is unrealized.
- **File drag actions:** grid, list and desktop drag sources now offer both copy
  and move, enabling modifier-key negotiation. Multiple-file drops also work on
  breadcrumb segments, in addition to the existing view, folder and sidebar targets.
- **Manual clock:** turn automatic time off, choose a calendar date and hours/minutes
  in 24-hour format, then apply in the selected local timezone. The clock refresh
  timer is removed when the page is unrealized.
- **Network filesystem bridge:** `gvfs-fuse` is explicitly included with GVFS and
  its backends, declared as a desktop-package dependency, and checked by the image gate. The package is not a dependency of
  Debian's base GVFS package, and the image installs without recommendations.
  Its FUSE paths let the existing file workers and non-GIO apps use mounted shares.
  This uses the [standard Debian component](https://packages.debian.org/trixie/gvfs-fuse)
  and [upstream GVFS path mapping](https://gitlab.gnome.org/GNOME/gvfs/-/blob/master/client/gdaemonfile.c).
- **WSL instructions:** the docs now provide a one-monitor 1920×1080 QEMU command
  with CPU emulation, without assuming `/dev/kvm` or GPU acceleration is present.

## Verification and limits

The unit suite passed **431 tests, with one existing skip**. Thirty-four new cases
cover transfer recovery, resumable downloads, shared bookmarks and file clipboard
parsing/ownership, optional network metadata and external drag modifiers. Eight original failure cases were reproduced before their fixes.

Native GTK checks in a two-output headless Wayland session passed:

- adding/renaming/removing favorites across two Files windows;
- replacing a file selection with external text or another file list;
- actual asynchronous GNOME cut MIME reads;
- preserving a failed cut and completing it with Retry;
- copy/move actions in grid/list and multiple-file view/breadcrumb drops;
- pointer hit testing, file context menus and drag preparation in both views
  after garbage collection;
- delayed network navigation cancellation and stale-response rejection;
- GIO Undo errors releasing the busy state;
- sidebar monitor cleanup;
- responsive authorization and rollback for NTP, timezone, power button, lid and
  charging limit; manual calendar/hour/minute application;
- existing context-menu, display keep/revert/timeout, file-history, desktop-action
  and Assistant streaming/attachment regression checks.

A real SFTP server in an isolated QEMU VM passed opening a network folder, copying
to and from it, cutting to it, Undo/Redo, file drops and saving the remote folder
as a favorite. The test runs with `G_DEBUG=fatal-criticals`. The baseline ISO
lacked `gvfs-fuse`; installing that standard package in the test guest made the
network locations usable by the existing path-based worker. The source package
list and image gate now require it.

Actual QEMU pointer/keyboard input also passed Ctrl-copy (source retained),
Shift-move, Undo after moving, the default move into a folder, multiple-file
selection by dragging empty space, and Ctrl-copy from list view. The driver lets
the tablet pointer settle before pressing; otherwise asynchronous input can
start a selection on the preceding file tile. These checks run with
`tests/interact/files_drag.py ISO --push`, or `make test-files-drag` for a rebuilt
image.

The reusable VM network check is `tests/interact/network_files.py`: pass an ISO and
`--push --install-dependency` to test these sources against the old image, or omit
those flags to verify the rebuilt image itself.

The clock and battery authorization tests use simulated administrative responses;
they do not change the host clock or claim to validate laptop firmware. Real NAS
hardware, Bluetooth peripherals and the user's Hyper-V graphics driver require
hardware-specific checks. The existing ISO predates these source changes; image
contents need a rebuild. The initial audit's BIOS/UEFI installation results remain
baseline evidence, not validation of a rebuilt image containing these changes.

Logs and visual evidence are under `work/audit-followup-2026-10-11/`. New native
regressions run with `make test-system-native`, including the administrative
concurrency check in a disposable container. The image gate runs with
`make test-image`, and `make test-network-files` runs the SFTP test against a rebuilt
image. The real SFTP test exercises a dedicated server in an isolated QEMU VM
rather than the user's live Hyper-V VM. The final static suite passed after
rebuilding all ten translation catalogs, the 74-page manual and the website;
generated pages and their links match their sources.
