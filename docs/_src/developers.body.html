Ptyxis, the terminal, has tabs, profiles and one-click shells inside your distrobox, toolbox and podman containers. Add an informative prompt (git status, language versions, command duration), Ctrl+R fuzzy history and sensible aliases. Docker starts on first use, so it costs nothing at boot.

portop shows what's using every port (process, systemd service or Docker container) and stops it with one key. pkgtui searches, installs, removes and upgrades apt, Flatpak and Snap packages from one terminal UI.

AI for developers

Your terminal understands you.

With Aurora AI turned on, ask turns a sentence into a command (it runs only if you say yes) and cmd 2>&1 | why explains a failure and the fix. Right-click a source file in Files and ask about it, or search your projects in Spotlight by name: Enter opens them in your editor.

From the repository

Build it, run it, preview the site.

Everything runs in Docker; QEMU/KVM boots the result. Install docker.io qemu-system-x86 qemu-utils ovmf first.

💿 Build and boot the ISO

make iso        # out/aurora-os-0.1-amd64.iso
make run        # boot it in a QEMU window (BIOS)
make run-uefi   # the same with UEFI firmware
make test       # static, unit and smoke tests

No repository? Boot the ISO alone with the command in the install guide.

🌐 Preview this website

make site                  # rebuild the pages
tools/serve-site.py --open # http://127.0.0.1:4173
tools/serve-site.py --lan  # also for other devices on your network

It serves docs/, the same folder GitHub Pages publishes. With --lan it prints the address to open from a phone or another PC. If the port is taken it moves to the next free one; --port picks another.
