Game Hub

Steam, Proton, Heroic, Lutris, Bottles and Waydroid: gaming set up in one click.

  • Choice: the Dev Hub window with a games catalog: Steam, Heroic, Bottles and ProtonUp-Qt from Flathub (sandboxed, with their own graphics runtimes, always current), Lutris, GameMode and MangoHud from Debian, Waydroid from its official repository.
  • Why: gaming on Linux is great today but setup is scattered. One click each, from the sources their developers recommend.
