Everyday file and settings reliability

The image includes gvfs-fuse alongside GVFS and its network backends, so mounted shares expose paths usable by ordinary apps and the existing file-operation worker.

The image includes gvfs-fuse alongside GVFS and its network backends, so mounted shares expose paths usable by ordinary apps and the existing file-operation worker. The image gate checks that this dependency is installed.

Files lets you Add to Sidebar from a folder's context menu, from empty space for the current folder, or from an existing place's menu. Favorite folders have Rename Bookmark… and Remove from Sidebar; removing a favorite keeps its files. Favorites use GTK's shared ~/.config/gtk-3.0/bookmarks format, support network URIs, and update across open windows and compatible file choosers.

Grid, list and desktop file drags offer both copy and move. Files accepts multiple files dropped onto folders, empty space, sidebar places and path segments. Folder drops prefer moving when the source permits it. The negotiated action decides whether to copy or move; hold Ctrl to request copy or Shift to request move. Network navigation uses cancellable asynchronous GIO requests, so an unresponsive server does not freeze GTK or override a later navigation. Transfers keep their progress, cancellation, retry and undo history. Copying into a folder's own subtree through a symlink is rejected; special files such as named pipes fail promptly instead of hanging the operation. Moves preserve a destination created by another process while the name was being chosen.

Drag gesture capture happens above the built-in selection controls, and the files hit on the initial press remain the source when GTK draws its selection overlay. Dragging empty space still draws a rectangle to select multiple files. Wayland modifiers come from the seat keyboard and the negotiated action survives asynchronous payload reads.

File clipboard ownership follows the system clipboard: copying text or files in another app replaces the previous Files selection. The standard GTK file list and GNOME x-special/gnome-copied-files format support copy/cut interoperability. A failed or cancelled cut in Files retains the remaining files for another paste; a successful move clears that cut without replacing a newer clipboard selection.

Settings → Date & Time adds a calendar, hour and minute controls, and Apply Date and Time when automatic time is off. Clock, timezone, power-button, lid and battery charge-limit changes wait for authorization in a worker; GTK remains responsive, repeat requests are blocked while pending, and cancellation restores the previous selection. AI component downloads retain interrupted partial files for resumption, verify an existing download's checksum, and finalize an already complete partial file without an unnecessary network request.

Evidence and remaining limits are in the follow-up audit. The corresponding native GTK regression checks are part of tests/settings-system-interactions.sh.

The 12 October cross-component audit covers recording, notifications, clipboard history, Windows migration, USB checksum selection, image resizing and batch renaming. Recorder shutdown runs outside the shell thread, with a saving state and automatic cleanup when the process exits. Pinned text entries survive a full clipboard history, and watcher/UI edits share a lock. Windows migration preserves existing exports and destination links; USB checksum records match the complete image filename. Image encoding uses a temporary output before replacing an original, and batch renaming rejects paths outside the selected folder. Do Not Disturb preserves notification IDs and timers, so progress updates replace one history entry and a closed notification emits its closing signal only once.
