These are the system-wide shortcuts of a new account, generated from Aurora's default configuration (/usr/share/aurora/labwc/rc.xml). Your own copy is ~/.config/labwc/rc.xml; change them, or add your own, in Settings → Keyboard → Shortcuts. Super+/ shows the ones in effect on screen. They work in both sessions unless marked.

In Files

See Files → Keyboard shortcuts.

With Aurora Shell running, aurora-shell COMMAND asks it to do something, which is handy in scripts and for your own shortcuts (Settings → Keyboard → Shortcuts → Add, with the command). Without a command, aurora-shell starts the shell (the session does this).

Example: a shortcut that snaps the window to the right third runs aurora-shell snap right-third.

Administrator helper

/usr/libexec/aurora-admin is the one audited program that performs privileged actions for Settings (firewall rules, the login manager's automatic login, the battery limit…), through polkit, which asks for the administrator password.

Set in every session

Set by Aurora at runtime

AURORA_COMPOSITOR
wayfire or labwc: the compositor actually running.
WAYFIRE_SOCKET
Wayfire's IPC socket (Aurora session), used by Snap Layouts and Task Manager.
WLR_RENDERER, LIBGL_ALWAYS_SOFTWARE, WLR_RENDERER_ALLOW_SOFTWARE
Set by aurora-render-env for machines without 3D.

You can set

AURORA_SAFE_GRAPHICS=1
Use the Compatibility session with software drawing (what the safe graphics boot entry does).
AURORA_LIBDIR
Where Aurora's Python code is (default /usr/lib/aurora): run a development checkout with AURORA_LIBDIR=~/src/auroraOS/desktop aurora-files.

Compositor
The program that draws windows on the screen and passes them input: Wayfire or labwc in Aurora.
Wayland
The modern way Linux apps show windows. Older X11 apps run through Xwayland.
Shell
Aurora Shell: the top bar, dock, desktop, Spotlight, notifications and widgets. (Also: the command interpreter in a terminal, bash.)
Layer surface
A part of the desktop that isn't a window (bar, dock, wallpaper), drawn above or below windows.
Greeter
The login screen.
Session
Everything that runs from login to logout.
Snapshot
An instant copy of the system on btrfs, to go back to after a bad update.
Flatpak
A format for sandboxed apps that work on any distribution; Flathub is its main store.
Portal
The way sandboxed apps ask for files, the camera or the screen.
polkit
The system that asks for the administrator password for privileged actions.
Live session
Aurora running from the USB stick without installing.
