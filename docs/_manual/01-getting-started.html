Aurora OS is a desktop Linux distribution built on Debian 13 “trixie”. It runs its own desktop, written for Aurora in Python with GTK 4 and libadwaita, on the Wayfire Wayland compositor (with labwc as a compatibility session). It ships as a live ISO that you can try without installing and install with a graphical installer.

Versions

This documentation describes the latest Aurora OS release. Aurora follows Debian trixie for the base system and the Linux 6.12 LTS kernel; Aurora's own desktop is updated through the aurora-desktop and aurora-artwork packages. See Updates and restarts.

Hardware support

  • Firmware for Intel, AMD, Realtek, Atheros, Broadcom and MediaTek Wi-Fi and Bluetooth, GPUs and audio (Sound Open Firmware).
  • Mesa with Vulkan and VA-API video decoding, the Intel media driver; NVIDIA cards are detected and Settings → Software Updates → Additional Drivers installs the recommended proprietary driver.
  • Laptops: power profiles, thermald, screen rotation, firmware updates (fwupd), backlight, battery health and an 80% charge limit where the firmware supports it.
  • Fingerprint readers (fprintd), printers (CUPS, driverless IPP) and scanners.
  • Virtual machines: QEMU/KVM (guest agent, SPICE), VirtualBox, VMware and Hyper-V guest tools are included. See Virtual machines.

Secure Boot. The live USB's boot loader is not signed yet: turn Secure Boot off in the firmware settings to start it. An installed system on UEFI can use Secure Boot again (it boots through Debian's signed shim).

The ISO

Aurora OS is an image named aurora-os-VERSION-amd64.iso that boots on BIOS and UEFI computers. Download it from the website or build it yourself (Building Aurora). GitHub limits files to 2 GB, so a larger image is published in numbered parts. Download every part and join them first:

cat aurora-os-VERSION-amd64.iso.part-* > aurora-os-VERSION-amd64.iso

Then check the reconstructed image against its checksum file before writing it:

sha256sum -c aurora-os-VERSION-amd64.iso.sha256

The output must say OK. If it doesn't, download the ISO again.

Write it to a USB stick

Use a stick of 4 GB or more. Everything on it is erased.

On any system

  • balenaEtcher or Fedora Media Writer: choose the ISO, choose the stick, write.
  • Ventoy: copy the ISO onto a Ventoy stick like any file; Ventoy shows it in its menu.
  • Rufus on Windows: choose DD image mode when it asks.

On Linux, from a terminal

Find the stick's device name with lsblk (for example /dev/sdb), then write the image. Check the name twice: writing to the wrong disk destroys its data.

sudo dd if=aurora-os-VERSION-amd64.iso of=/dev/sdX bs=4M status=progress oflag=sync

Try it without a USB stick

Boot the ISO in a virtual machine: QEMU, GNOME Boxes, virt-manager, VirtualBox, VMware or Hyper-V. See Virtual machines.

Starting from the USB stick

  1. Plug in the stick and restart the computer.
  2. Open the firmware's boot menu. The key depends on the maker: usually F12, F10, F9, F11, Esc or Del, pressed right after switching on.
  3. Choose the USB stick (on UEFI computers, the entry that starts with “UEFI”).

Boot parameters

Press E on an entry to edit its kernel line for one boot (press Ctrl+X or F10 to start). Useful additions:

aurora.lang=it_IT.UTF-8
The live session's language.
aurora.kbd=it
The keyboard layout; several separated by commas (us,ru), switched with Alt+Shift.
aurora.safegraphics
Use the Compatibility session with software drawing.
nomodeset
Disables the kernel's graphics drivers: a last resort for a black screen.
aurora.install
Open the installer after the desktop starts (what “Install Aurora OS” adds).

The live session is a complete Aurora desktop that runs from the USB stick and from memory. It works like Ubuntu's “Try Ubuntu”: use it as long as you like; nothing is written to the computer's disks, and everything you change is lost when you shut down.

What is different from an installed system

  • You are logged in automatically as the user aurora, which has no password. sudo works without one.
  • The screen doesn't lock when idle, and the computer doesn't suspend by itself (that would interrupt an installation).
  • The desktop shows Install Aurora OS, and so does the dock.
  • Snapshots, fingerprint and automatic updates are not active.
  • A warning about low disk space is not shown (the live system's “disk” is memory).

Starting the installer

Double-click Install Aurora OS on the desktop, or use its icon in the dock. If the installer is already open it comes forward; after you close it, the icon opens it again. See Installing Aurora OS.

The installer is Calamares with Aurora's look: the steps run across the top as dots that fill in as you go, and there is one Next button. Everything it needs is on the USB stick, so it works offline.

Back up your files before installing, above all if you are going to change partitions or install next to another system.

Steps

  1. Welcome. Choose the installer's language. It checks the requirements: 20 GB of disk, 2 GB of memory, and the power cable on a laptop.
  2. Location. Click your region on the map, or let it be detected. This sets the time zone and the formats for dates, numbers and units. Day and month names always follow the system language; units, numbers and money follow the region.
  3. Keyboard. Pick the layout and its variant, and type in the test field. Not sure which one you have? Click Detect…: it asks two or three questions about what is printed on your keys (which letters start the top row, which character is next to L) and selects the layout.
  4. Disk. Choose where Aurora goes:
    • Erase disk: a clean install on the whole disk. Tick Encrypt system for full-disk encryption (LUKS2) and choose a passphrase: you'll type it at every start.
    • Install alongside: keeps Windows or another Linux; drag the divider to share the disk.
    • Replace a partition: installs onto one existing partition.
    • Manual partitioning: full control. Aurora needs a root partition (/) and, on UEFI, an EFI system partition (FAT32, 300 MB or more, mounted on /boot/efi).
    The file system is btrfs by default, which gives automatic system snapshots and rollback from the boot menu (see Snapshots and recovery). ext4 and xfs are available without snapshots. The partition legend shows each partition's name and size.
  5. Users. Your full name, user name, password (twice) and the computer's name. Choose Log in automatically to skip the login screen, or leave it off to see it at every start.
  6. Summary. Review every choice. Install starts writing to the disk; until then nothing has changed.
  7. Installing. A slideshow runs while files are copied, with a progress bar.
  8. Finish. Tick Restart now and click Done. Remove the USB stick when the computer restarts.

What the installer sets up

  • The boot loader: GRUB, through Debian's signed shim on UEFI (Secure Boot works), or GRUB on the disk on BIOS.
  • On btrfs: subvolumes @ (system) and @home (your files) with compression, Timeshift, a “Fresh install” snapshot at first boot and the snapshots boot menu.
  • Compressed swap in memory (zram).
  • The firewall (on), automatic security updates (on), and the trixie-backports source for newer kernels when you want them.

If the installation fails, the installer offers to save its log. Settings → System Health → Guided Diagnostics can prepare an installation report on the next try (see Troubleshooting).

After the restart you see the login screen (or the desktop, with automatic login), then the Welcome app. It runs once per user and shows:

  • light or dark style;
  • the most useful keyboard shortcuts;
  • where to find apps and settings.

Open it again any time from Launchpad (Welcome).

Worth doing first

  1. Connect to the internet from the Control Center (Super+S) → Wi-Fi.
  2. Install updates: the system checks a few minutes after login and tells you. Or open App Center → Updates.
  3. Set up your fingerprint (Settings → Users), if you have a reader.
  4. Add online accounts (Settings → Users → Online Accounts) for mail, calendar and contacts.
  5. Pick your look: Settings → Appearance (style, accent color, background) and Settings → Desktop & Dock.
  6. Get your tools: Dev Hub for developer tools, Game Hub for games, App Center for everything else.
