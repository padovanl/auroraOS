Open Files from the dock, with Super+E, or by double-clicking a folder. From a terminal: aurora-files [FOLDER or LOCATION].

The window

Sidebar
Home, Desktop, Documents, Downloads, Music, Pictures, Videos, Trash, plugged-in drives (click to mount, ⏏ to eject), Computer (/), Network and Connect to Server…. Right-click a place for New Tab, New Window, Open in Terminal, Copy Path and Properties.
Path bar
Click a part of the path to go there; Ctrl+L to type a location (also smb://, sftp://, trash:///).
Tabs
Ctrl+T opens one, Ctrl+W closes it, Ctrl+Tab switches.
Views
Grid or list (Ctrl+1); hidden files with Ctrl+H; search in the folder with Ctrl+F. Drag on empty space to select several.
Git
Inside a Git repository, changed files show a badge.

The file menu (right-click)

Open, Open With…
With the default app, or choose another one.
Quick Look
A preview without opening (Space). See Quick Look.
Send to Nearby Device…
Sends with LocalSend to a phone or computer on the same network.
Summarize with Aurora, Ask Aurora About This File…
With Aurora AI on (Settings → AI → Files).
Extract Here
For archives (zip, 7z, rar, tar.gz, tar.xz, tar.zst…): unpacks next to them.
Compress…
Packs the selection into one archive: choose the name and the format — ZIP (opens everywhere, Windows included), 7-Zip (smaller) or tar.xz (smallest, keeps Linux permissions).
Cut, Copy, Duplicate, Rename…
Pasting shows progress, can be cancelled, and offers to retry if something fails.
Rename Multiple…
For several files: replace a piece of text in all their names at once. No file is ever overwritten.
Compare Folders
For two folders: what is only in one, and what differs.
SHA-256 Checksums
Computes them in the background, to check a download.
Move to Trash, Properties
Properties shows size, type, dates, location and permissions.

On empty space: New Folder…, New File… (from templates in ~/Templates), Paste, Select All, Open in Terminal, Properties.

Undo and Redo (Ctrl+Z, Ctrl+Shift+Z) work for moves, renames, copies and moving to the Trash.

Trash

Items moved to the Trash can be restored to where they were (Restore) or deleted for good (Delete Permanently, or Shift+Delete without the Trash). Empty Trash deletes everything in it. Storage Sense can empty old items by itself (Storage).

Network folders

Network in the sidebar lists computers and NAS boxes that share folders on your network (Windows computers announce themselves with WS-Discovery). Connect to Server… opens any address:

AddressFor
smb://192.168.1.10/Shared or \\nas\SharedA Windows or NAS shared folder (SMB)
sftp://user@server/pathAny computer with SSH
ftp://serverFTP
davs://server/remote.php/dav/files/userWebDAV (Nextcloud, ownCloud)

When a password is needed, Files asks, and can remember it in your keyring. Connected servers appear in the sidebar with ⏏ to disconnect.

Keyboard shortcuts in Files

Open it with Ctrl+Shift+Esc, from the Aurora menu, from Launchpad, or with aurora-taskmanager.

Processes

Three groups, each with CPU (a share of the whole computer, as on Windows), memory and disk activity:

Apps
Everything that has a window. An app's processes (for example a browser's many content processes) are folded under it with their count; double-click or right-click → Expand to see them.
Background processes
Your other processes: the shell, the compositor, sound, sync clients…
System processes
Other users' and the system's, when Show system processes is ticked.

Click a column's title to sort by it. Busy values are highlighted.

End Task (Delete)
Asks the app to quit, like closing it.
Kill (Shift+Delete)
Stops it at once, without saving.
Open File Location
Shows the program's file in Files.

System processes can only be stopped by the administrator; use sudo kill PID in a terminal.

Performance

The last minute as graphs in your accent color:

  • Processor: use, cores, average speed, up time.
  • Memory: in use and total, available, cached, swap in use.
  • Disk: read and write speed of the whole disks, free space and capacity.
  • Network: total speed, receive and send.

Startup Apps

The apps that start when you log in (XDG autostart), with a switch each. Turning one off writes an override in ~/.config/autostart; the system's own file is never changed.

Services

The system's and your own services (systemd units), with their state, filtered by the search box. Start, Stop and Restart: your own services directly, system services after the administrator password.

Open Settings with Super+I, from the Aurora menu, from the Control Center, or by typing a setting's name in Spotlight. The sidebar groups pages like Ubuntu's Settings: connectivity, look and feel, devices and input, security, AI, and the system.

Open a page directly from a terminal or a script:

Every option of every page is listed in the Settings reference.

App Center (GNOME Software) installs, updates and removes apps from two sources:

  • Debian: the whole Debian trixie archive, tens of thousands of packages, maintained by Debian's security team.
  • Flathub: sandboxed apps, always at their latest version, many commercial apps (Spotify, Zoom, Discord, Slack…).

When an app exists in both, choose the source on its page. Updates lists system, app and firmware updates. Nothing is installed without you asking.

From a terminal

sudo apt install PACKAGE            # a Debian package
flatpak install flathub APP.ID      # a Flatpak app
pkgtui                              # search and install both in one terminal UI

Apps' Flatpak permissions (camera, files, location…) can be reviewed in Settings → App Permissions.

Dev Hub installs developer tools from their official sources, so they are always current. Each install runs in a visible terminal, showing every command; anything that needs the administrator asks for the password there. Installed tools show a check mark.

Project Workspaces

For each repository or folder, a workspace opens your editor, a terminal and Files together; in the Aurora session it can also remember where those windows were and put them back. Spotlight finds projects by name and opens their workspace from the right-click menu.

Catalog

Game Hub sets up gaming in one click each. Steam, Heroic, Bottles and ProtonUp-Qt come from Flathub (sandboxed, with their own graphics runtime); GameMode, MangoHud and Lutris are Debian packages; Waydroid comes from its official repository.

In Steam, turn on Settings → Compatibility → Enable Steam Play for all other titles to run Windows games with Proton.

Open a terminal with Super+Enter or Ctrl+Alt+T. The terminal is Ptyxis: tabs, profiles, and a menu to open shells inside distrobox, toolbox and podman containers. The font is JetBrains Mono.

The shell

  • bash by default, with Aurora's defaults in /etc/aurora/bashrc; add your own in ~/.bashrc. Dev Hub → Shells & Terminals installs zsh, fish and others and switches the default.
  • The prompt is starship: Git branch and status, language versions, command duration. Customize it in ~/.config/starship.toml (start from /etc/aurora/starship.toml).
  • Ctrl+R searches the history with fzf.
  • Aliases: ll, la, g (git), lg (lazygit), dc (docker compose), and bat, fd.

Preinstalled tools

git, git-lfs, lazygit, delta, build-essential, gdb, cmake, shellcheck, Python (pip, venv, pipx), Node.js and npm, Docker (with compose and buildx), Podman, distrobox, neovim, tmux, ripgrep, fd, fzf, bat, btop, jq, httpie, direnv, tldr, starship, zsh, network tools (ifconfig, dig, traceroute, mtr, netcat, whois), portop and pkgtui.

  • docker works for your user right away; the daemon starts on first use.
  • distrobox create -i fedora gives you a Fedora (or Arch, Ubuntu…) container integrated with the desktop.
  • portop shows which process listens on which port and stops it with one key.

Screenshots are saved to ~/Pictures/Screenshots and copied to the clipboard. The notification offers:

  • Annotate: arrows, text, highlighter, blur and crop (swappy);
  • Copy Text: recognizes the text in it;
  • Ask Aurora: explains what's on screen (with Aurora AI on).

Text recognition works offline with Tesseract, in English plus your language (18 scripts).

Recording the screen

Control Center → Screen Recording starts; a red dot appears in the top bar; the same tile stops. Recordings are MP4 files in ~/Videos/Screencasts. For more control (sound, webcam, streaming) install OBS Studio from App Center.

Clipboard history

Super+V shows what you copied lately, newest first, in Spotlight. Type to filter; Enter copies an entry again (then paste with Ctrl+V). Copied images are kept too. Pinned entries stay until you unpin them; the others are forgotten after a while.

Settings → Privacy & Security → Clipboard History turns it off (Remember copied text), clears it, and Manage Clipboard History… pins and deletes entries. The history stays on this computer. The Clipboard widget shows the latest entries on the desktop.

Emoji

Super+. opens the emoji picker; type a word (heart, rocket, smile) and Enter copies it. In Spotlight, start with :.

Select a file in Files and press Space. Quick Look previews:

  • pictures (with zoom), videos and audio (playable);
  • PDF pages;
  • source code and text, with syntax highlighting;
  • folders (their contents and size).

← and → move to the previous and next file; Space or Esc closes; Open opens the file in its app. From a terminal: aurora-quicklook FILE.

Aurora includes the everyday apps Ubuntu ships (GTK 4 versions where they exist), plus its own. Each is checked by Aurora's tests to be installed, visible and able to start.

Default apps for web, mail, music, video, pictures and so on are chosen in Settings → Apps.
