Requirements

A Linux computer with Docker (or Podman), about 25 GB of free disk space and a network connection. Building takes 20–60 minutes the first time.

Build

git clone https://github.com/padovanl/auroraOS
cd auroraOS
make iso          # out/aurora-os-VERSION-amd64.iso and its .sha256

Changing the desktop without rebuilding

The desktop is Python: run it from a checkout with AURORA_LIBDIR=$PWD/desktop desktop/bin/aurora-files, or start a headless development session with the tools in desktop/dev/. In a running VM, tests/interact/serve.py and do.py push the checkout's code and drive the desktop.

Every app with a libadwaita window imports aurora.plaintext first: rows (Adw.ActionRow, ComboRow, SwitchRow…) and toasts then show their title and subtitle as plain text, so names with & or < appear as they are. Pass use_markup=True to a row that needs markup.

CommandWhat it checks
make test-staticSyntax, shellcheck, desktop files, schemas, XML, installer configuration, translations, the website and this documentation being up to date.
make test-unitpytest unit tests in tests/unit/.
make test-smokeStarts the shell headless and opens every app and Settings page.
make test-imageInspects a built ISO: apps, themes, services, boot records.
make test-bootBoots the ISO with BIOS and UEFI, checks the session and starts every default app marked yes in config/apps.manifest. Transmission is marked no: a BitTorrent client joining its network from a test VM triggers company firewalls' P2P alerts (the VM's traffic leaves with the host's address).
make test-interactUses the live desktop like a person: clicks, keys, windows.
make test-newfeaturesDrives this release's new work on the real system, in the Aurora session: the five icon styles one after another (each must redraw the dock), Launchpad in pages and a folder made from two apps, the background's movement and that Still really is still, window previews in the overview with the setting on and off, and that Clipboard, USB Stick Writer and Migrate from Windows each open a window. Every check is a measurement on a screenshot or a question to the shell, not a look.
make test-shortcutsPresses the documented system-wide keyboard shortcuts in a VM and checks their visible effects, launched apps and window states.
make test-shortcut-edgesRepeats and overlaps shortcuts, cancels modal selection tools, mixes window states and checks that no input grab or process is left behind.
make test-files-shortcutsDrives Files in a VM with its documented keys, including Quick Look, navigation, tabs, chained undo/redo, focus handling and rapid asynchronous operations.
make test-installInstalls Aurora in a VM and checks the installed system.
  1. Strings are marked with gettext (_("…")) in the domain aurora. Regenerate the template: make -C desktop pot. It also takes the apps' names and descriptions from desktop/data/applications/*.desktop; make install writes them back with every language (Name[it]=File), so Launchpad and the dock show them translated. A language needs its line in desktop/po/LINGUAS.
  2. Translations are kept as JSON in desktop/po/sources/LANG.json: English text → translation; plurals as a list with one form per plural category.
  3. Build the .po file: tools/po-from-json.py LANG. It rejects a translation whose {placeholders} differ from the English, so a typo can't break the app.
  4. To add a language to the system, add a line to config/locales.list.
  • Report a problem: open an issue on GitHub. Attach a report from Settings → System Health → Guided Diagnostics (review it first).
  • Send a change: fork, branch, run make test, open a pull request. Keep code, comments and documentation in English.
  • Documentation: edit docs/_manual/ and run make manual. Reference pages are generated from the code: fix the code (or its descriptions in tools/build-manual.py), not the generated HTML.
