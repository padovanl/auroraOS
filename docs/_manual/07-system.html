What updates itself

  • Security updates are installed automatically in the background (unattended-upgrades), like on Ubuntu. Turn it off in Settings → Software Updates.
  • Other updates are checked a few minutes after login and every six hours; a notification says how many are ready, with Update (opens App Center → Updates).
  • Flatpak apps and firmware (fwupd) are updated in App Center too.
  • Aurora's desktop (aurora-desktop, aurora-artwork) comes from Aurora's signed repository like any other package.

Before every update and package installation a system snapshot is taken (on btrfs, see Snapshots).

Restarts

Some updates (a new kernel, core libraries) need a restart. Aurora notices and shows Restart to finish updating with three choices:

Restart Now
Restarts right away.
Tonight
Plans the restart for the end of your active hours.
Later
Reminds you later.

Settings → Software Updates → Restarts:

  • Active hours (start and end, 8:00–23:00 by default): Aurora never restarts by itself during them.
  • Restart automatically outside active hours (off by default): when an update needs it, Aurora plans the restart outside your active hours by itself.

Five minutes before a planned restart a notification warns you, with Restart Now and In an Hour to postpone.

From a terminal

sudo apt update && sudo apt full-upgrade     # everything from Debian and Aurora
flatpak update                               # Flatpak apps
sudo fwupdmgr update                         # firmware

Newer kernels

Aurora uses Debian's Linux 6.12 LTS kernel, which gets fixes automatically. For brand-new hardware, a newer kernel comes from trixie-backports, enabled by the installer:

sudo apt install -t trixie-backports linux-image-amd64

Versions

Within Debian trixie, major versions don't jump (Python, Node.js…): that is what keeps the system stable. Newer toolchains come from Dev Hub, Flatpak or containers.

On a btrfs installation (the installer's default) Aurora keeps snapshots of the system:

  • Fresh install, taken at the first boot;
  • one before every update or package installation (the last 10);
  • daily (the last 5) and weekly (the last 3).

Snapshots are instant and only take the space of what changes afterwards. They cover the system, not your files in Home: rolling back never loses your documents.

If an update breaks something

  1. Restart. In the boot menu choose Aurora OS snapshots (hold Shift or press Esc while starting if the menu is hidden), then the snapshot from before the update.
  2. Aurora starts as it was then (read-only for the system). Check that everything works.
  3. Open Timeshift (Settings → Software Updates → Open Timeshift), select the same snapshot and click Restore. Restart once more: the rollback is permanent.

Managing snapshots

  • Settings → Software Updates → Take a Snapshot Now, or turn the automatic ones off (Snapshot before every update).
  • Timeshift lists, deletes and restores them, and sets how many are kept.

On ext4 or xfs there are no automatic snapshots or boot-menu rollback; Timeshift can still make copies with rsync.

Snapshots protect the system; Backups (Déjà Dup) protects your files.

  1. Open Backups from Launchpad.
  2. Choose the folders to save (Home by default) and to leave out (Trash, Downloads…).
  3. Choose where: an external drive, a network folder or a cloud account (Google Drive, Microsoft OneDrive through Online Accounts).
  4. Turn on automatic backups (daily or weekly). Backups are incremental and can be encrypted with a password.

To restore, open Backups → Restore and pick the date.

Settings → Storage, like Windows' Storage page.

Disk

Free and total space of the disk that holds your home folder, as one bar colored by kind of file.

What takes the space

Apps (Debian packages and Flatpak), Documents, Pictures, Music, Videos, Downloads, Desktop, temporary files and cache, the Trash, other files in your folder, and the system. Click a folder's row to open it in Files, Apps to open Settings → Apps.

Clean up now

Empty the Trash
Deletes everything in the Trash.
Clear temporary files and cache
Empties ~/.cache; apps remake what they need.
Downloads older than 30 days
Review… lists them and moves them to the Trash, so you can still get them back.

Storage Sense

Cleans up by itself, two minutes after login and then every four hours:

  • Empty old items from the Trash;
  • Delete old temporary files (yours in /tmp);
  • Old means older than: 1 week, 2 weeks, 30 days or 60 days;
  • Move unused Downloads to the Trash: never, or after 2 weeks, 30 or 60 days.

More

Disks and partitions opens GNOME Disks (format, check health, mount). See every folder's size opens Disk Usage Analyzer.

Settings → Screen Time.

  • Today: the total, the daily average of the week, and the last seven days as bars (today in your accent color).
  • Apps today: each app's time, most used first.
  • Daily limit next to each app: 15 or 30 minutes, 1, 2 or 3 hours. When an app reaches it, a notification says so (once a day). The app keeps working: it's a reminder, not a lock.

Time is counted for the app whose window is in front, every 30 seconds, only while the screen is unlocked. It is kept in ~/.local/share/aurora/screentime/, one file per day, never leaves the computer, and days older than five weeks are forgotten. Count screen time turns it off; Clear Screen Time History deletes it.

Built in

  • Firewall on by default (ufw): incoming connections are blocked, outgoing allowed. Settings → Privacy & Security → Firewall. Ports for sharing open only while that sharing is on.
  • Automatic security updates.
  • AppArmor confines services and several apps.
  • Full-disk encryption (LUKS), chosen in the installer.
  • Secure Boot on installed UEFI systems.
  • No telemetry, no crash uploads, no ads, no account required.

Administrator

The first user is an administrator (in the sudo group). Settings never runs as root: when an action needs it, a password prompt appears (polkit). With a fingerprint set up, the finger works for sudo and these prompts, but never for the login and lock screens (the password also unlocks your keyring).

App permissions

Settings → App Permissions lists what Flatpak apps were allowed through portals (camera, microphone, location, screenshots, background running…) and lets you revoke it.

Privacy & Security page

Screen lock, file history (Remember recent files, Clear History…), clipboard history, online services (weather) and the firewall.

What goes online by itself

Every network request the desktop makes on its own, all optional:

  • Weather: Open-Meteo, with the chosen or approximate position, when the weather is shown.
  • Location: GeoClue, only when no city is chosen in Weather.
  • Exchange rates: the European Central Bank's public file, only when you type a currency conversion.
  • Picture of the day: Bing, NASA or Wikimedia, once a day, only if you chose that background.
  • Updates: Debian's, Aurora's and Flathub's servers.
  • Aurora AI: nothing while it runs on your computer; downloads when you set up a feature; your questions go to a cloud provider only if you choose one.

Sun position, OCR, clipboard history, emoji, unit conversion and screen time run offline.

No app starts by itself and goes online on its own. In particular the BitTorrent client (Transmission) only runs when you open it, and even then contacts nobody until you turn its peer network on (see Torrents).

Wi-Fi and wired

Control Center → Wi-Fi lists networks; click one to connect (a password field appears for protected networks). Settings → Network shows connected networks, saved ones, IP details, and Advanced (NetworkManager's connection editor) for static addresses, DNS and 802.1X.

Share your Wi-Fi

Settings → Network → the QR icon next to the connected network. Point a phone's camera at it to join.

Hotspot

Settings → Network → Advanced opens NetworkManager's connection editor: add a Wi-Fi connection in Hotspot mode to share the computer's connection over Wi-Fi. From a terminal: nmcli device wifi hotspot ssid NAME password PASSWORD.

VPN

WireGuard, OpenVPN and OpenConnect (Cisco AnyConnect, GlobalProtect…): Settings → Network → VPN. Import a configuration file or enter the details; connect from the same page.

Mobile hotspot

Control Center → Mobile Hotspot turns the computer into a Wi-Fi hotspot in one click: name, password and a QR code are under the tile's arrow (see Control Center). It needs a Wi-Fi card that supports access point mode, and the computer's own connection should come from a cable or another network.

Airplane mode

Control Center → Airplane Mode turns Wi-Fi and Bluetooth off together.

Network tools

ip a, ifconfig, ping, dig, traceroute, mtr, nc (netcat), whois, nmcli (NetworkManager from the command line) and portop are installed.

Settings → Sharing. Each kind of sharing opens its firewall port only while it is on.

Files with nearby devices

Right-click a file in Files → Send to Nearby Device… (LocalSend): works with Android, iPhone, Windows, macOS and Linux, over your network, with no account. Turn on Let nearby devices find this computer to receive files.

Your screen

Share this screen starts a VNC server (wayvnc, encrypted, with a password). Connect from another computer with Remmina, TigerVNC or RealVNC to the address and with the password shown.

Remote login

Remote Login (SSH) lets you log in to this computer from another one with ssh user@address. Off by default.

Your phone

  1. Install KDE Connect on your Android phone (Play Store or F-Droid) or iPhone (App Store).
  2. In Aurora: Settings → Sharing → Allow phones to connect.
  3. Pair from the phone.

The phone's notifications show up on the desktop; send files both ways, share the clipboard, control music and use the phone as a touchpad.

Network folders

To open folders shared by other computers, see Files → Network folders.

Displays

Settings → Displays lists each connected monitor with: on or off, resolution and refresh rate (★ marks the monitor's preferred mode), scale (100–200 %, for high-resolution screens) and orientation. As on Windows, a change must be confirmed: Keep Changes, or Revert, which also happens by itself after 15 seconds, so a mode the screen can't show never leaves you with a black screen.

Kept choices are saved in ~/.config/aurora/displays.sh and applied at login; in the Aurora session they also go into Wayfire's configuration, so they stay when it is reloaded. Monitors are placed side by side automatically; arranging them by hand and choosing the primary one aren't in Settings yet (wlr-randr --output NAME --pos X,Y does it for the session). Desktop widgets keep their places, as fractions of the screen, and move just enough not to overlap on a smaller screen or a larger scale.

Bluetooth

Settings → Bluetooth: turn it on, make the computer visible, pair new devices (keyboards, mice, headphones, phones) and connect or forget paired ones. The Control Center's Bluetooth tile connects paired devices quickly. Blueman offers advanced options.

Printers and scanners

Most network and USB printers work without drivers (driverless IPP): Settings → Printers → Add. Print queues and jobs are there too. Scan with Document Scanner.

Caps Lock and Num Lock

Pressing Caps Lock or Num Lock shows its new state on screen for a moment (“Caps Lock On”), whichever app you are typing in. Turn it off in Settings → Keyboard → Show Caps Lock and Num Lock on screen.

Keyboard and mouse

Settings → Keyboard (layouts, repeat, Compose key, shortcuts) and Mouse & Touchpad (speed, natural scrolling, tap to click, gestures, left-handed). See Languages and keyboards.

Settings → Sound.

  • Output: the device (speakers, headphones, HDMI, Bluetooth), volume and left/right balance.
  • Input: the microphone and its level.
  • Volume Mixer: every app playing sound right now, with its own volume slider and mute button, updated every two seconds. The same list is under the devices in the Control Center (arrow next to the volume).
  • Over-amplification: lets the volume go up to 150%, everywhere: here, the Control Center slider, the volume keys and the wheel over the top bar.
  • System Sounds: the startup and shutdown sounds, on or off, with a preview.

Media keys change the volume with an on-screen indicator. Sound runs on PipeWire; per-app volumes are set with wpctl, which also works from a terminal (wpctl status).

Settings → Power.

  • Screen blank and Automatic screen lock (see Locking and idle).
  • Automatic Suspend: after how long on battery and when plugged in.
  • Power button and Closing the lid (on laptops): what they do.
  • Power Mode: Performance, Balanced, Power Saver (also in the Control Center).
  • Battery: Show battery percentage in the top bar, Battery health, and Limit charging to 80% to make the battery last longer, on laptops whose firmware supports it (ThinkPad, ASUS, Dell, Framework, Huawei, LG, Samsung, System76…).

Battery Saver

Turn on Battery Saver (Settings → Power → Battery): never, or at 10%, 20% (default), 30% or 50%. Below that charge on battery, Aurora switches to the Power Saver mode and says so, with Turn Off; when you plug in, it goes back to the mode you had. If you chose Power Saver yourself, it is left alone.

Desktop Profiles (Settings → Desktop Profiles) switch several of these together: Battery uses Power Saver, hides the dock and turns animations off.

Settings → Accessibility.

Seeing

  • High contrast, text size (Default, Large, Larger), pointer size, reduce animation, always show scrollbars.
  • Screen reader (Orca): reads what's on screen.
  • Zoom: the whole screen or a lens. In Aurora Compatibility: Super+Alt+8 on/off, Super+Alt+= / − zoom in and out; in the Aurora session, hold Super and scroll.

Hearing

Alert sounds on or off; the visual notification popups always show.

Typing

  • Screen keyboard: Aurora's own on-screen keyboard, shown at every login when this is on, or on demand from the Control Center tile (see Control Center). It works in both sessions. Pick its look among ten themes in Keyboard theme: Aurora, Light (like a phone), Accent Color (follows the accent color), Glass (see-through), and six that change the keys' shape and lettering too: Mechanical (sculpted keycaps that travel when pressed), Comic (a halftone page, ink outlines and keys stuck on at angles, in Comic Neue), Typewriter (round chrome-rimmed keys in Courier), Synthwave (glowing neon on a grid), Pixel (8-bit square keys) and Candy (pastel pills).
  • Blinking cursor; repeat delay and speed are in Settings → Keyboard.
  • Dictation with Aurora AI (Super+H).

Pointing and clicking

Double-click delay; mouse speed and left-handed mode in Settings → Mouse & Touchpad.

Language

Settings → Language & Region: the interface language, and the formats (dates, numbers, units, money). Log out and in again to apply. Day and month names follow the interface language; numbers, units and money follow the region of the formats.

Your choice is kept in ~/.config/aurora/locale.conf; the system's default (from the installer) in /etc/default/locale.

Keyboard layouts

Settings → Keyboard (or Language & Region): add layouts; switch between them with Alt+Shift. The Compose key types special characters (Compose e ' gives é). Your layouts are kept in ~/.config/aurora/keyboard.conf.

Chinese, Korean and Japanese

Settings → Language & Region → Input Methods: Chinese (Pinyin), Korean (Hangul) and Japanese (Mozc). Type the sound in Latin letters and pick the characters from the suggestions that appear next to the cursor (Space takes the first, numbers the others; Hangul composes syllables as you type). Ctrl+Space switches between plain letters and the input method; the top bar shows which one is on (拼, 한, あ). It works with the on-screen keyboard too.

  • When the system language is Chinese, Korean or Japanese, its input method is on from the first login.
  • Turning one on for the first time needs a log out and in (apps learn about it when they start).
  • Your keyboard layouts stay: while an input method is on, Ctrl+Space goes through each layout from the list above, then each input method. Adding or removing a layout updates it right away.
  • Input method settings opens Fcitx's configuration: shortcuts, number of suggestions, fuzzy pinyin, the Shuangpin layouts.
  • Online suggestions (“Cloud Pinyin”) are off: they would send what you type to an online service. Turn them on in the input method settings if you want them.

Aurora uses Fcitx 5 with its Pinyin engine (libime), libhangul and Mozc. The choice is kept in ~/.config/aurora/input-methods and ~/.config/fcitx5/profile; Fcitx runs only when an input method is on.

Date and time

Settings → Date & Time: Automatic date & time (from the internet), the time zone and the 24-hour clock. Seconds in the top bar clock are in Settings → Desktop & Dock → Top Bar.
