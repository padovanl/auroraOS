System Health first

Settings → System Health checks disks (SMART), free space, updates, firmware, failed services, the battery, graphics drivers and the session's own startup, and shows a fix for each problem. Guided Diagnostics prepares a local report for installation, startup and login, or app problems: raw logs are left out unless you choose to include them, you can edit the preview, and nothing is uploaded.

The screen stays black after the boot menu

  1. Start Try Aurora OS (safe graphics).
  2. Still black: edit the entry with E and add nomodeset to the line that starts with linux.
  3. On an installed NVIDIA system: Settings → Software Updates → Additional Drivers.

The system doesn't start: recovery mode

In the boot menu choose Advanced options for Aurora GNU/Linux, then the entry ending in (recovery mode) (the previous kernel is there too, if the newest one is the problem). It starts only the essentials and, after Press Enter for system maintenance, gives a root terminal without asking a password: fix what's needed (apt, journalctl -xb to read what failed), then systemctl default to start normally or reboot. On btrfs, Aurora OS snapshots in the same menu starts yesterday's system instead.

The desktop doesn't appear after login

  • At the login screen choose Aurora Compatibility.
  • If the Aurora session fell back to labwc, the reason is in ~/.local/state/aurora/compositor-failure.log and in System Health.
  • If the top bar or dock disappear, the shell restarts by itself within a second (up to five times a minute). Its log is $XDG_RUNTIME_DIR/aurora-shell.log.
  • To log in without the desktop: Ctrl+Alt+F2 gives a text console.

An app doesn't respond

Open Task Manager (Ctrl+Shift+Esc), select it, End Task; if it stays, Kill. From a terminal: pkill NAME or kill -9 PID.

No sound

  • Control Center → the arrow next to the volume: choose the right output device.
  • Settings → Sound → Volume Mixer: is the app muted or very low?
  • systemctl --user restart pipewire wireplumber restarts the sound system.

No Wi-Fi

  • Airplane Mode off? Wi-Fi tile on?
  • nmcli radio shows whether Wi-Fi is blocked; rfkill list shows a hardware switch.
  • Some Broadcom and Realtek cards need a newer kernel: sudo apt install -t trixie-backports linux-image-amd64.

An update broke something

Start the snapshot from before the update from the boot menu: see Snapshots and recovery.

Reset settings

gsettings reset-recursively org.aurora.desktop    # Aurora's desktop settings
rm ~/.config/labwc/rc.xml                         # keyboard shortcuts and window settings
aurora-wayfire-config                             # regenerate the Aurora session's config

Log out and in again afterwards. Your files are not touched.

Is Aurora OS free?
Yes: free to use, share and change, under the GPL 3.0 or later. It has no ads, no telemetry and needs no account.
Can I install Windows programs?
Many: Game Hub sets up Bottles and Wine for Windows apps, and Steam's Proton for games. Look for a Linux version or a web version first (App Center, Flathub).
Can I use Android apps?
Game Hub installs Waydroid, which runs Android apps in a window.
Does it have a Microsoft Office equivalent?
LibreOffice (Writer, Calc, Impress) opens and saves Office files. Microsoft 365 works in the browser.
Where are my files?
In your home folder, /home/YOUR-NAME: Desktop, Documents, Downloads, Music, Pictures, Videos.
How do I install something that's not in App Center?
A .deb file: double-click it, or sudo apt install ./file.deb. An AppImage: make it executable in Properties and open it. Dev Hub covers most developer tools.
How do I become administrator in a terminal?
Put sudo before the command; it asks your password (or your finger).
Can I keep Windows?
Yes: Install alongside in the installer; the boot menu then lets you choose at every start.
Why is the Windows drive read-only?
Windows didn't shut down completely, so Linux must not write to its drive: Fast Startup (on by default in Windows 10 and 11) and hibernation leave it in use, and so does the disk check Windows runs once after Aurora is installed next to it. Files then opens it read-only and says so; your files are all there to copy. To change files on it, start Windows and choose Restart (not Shut down) back into Aurora, or turn Fast Startup off in Windows (Control Panel → Power Options → Choose what the power buttons do). Opening it asks for your password once.
Why does the time differ from Windows after switching?
Windows keeps the hardware clock in local time, Linux in UTC. Run timedatectl set-local-rtc 1 in Aurora, or set Windows to UTC.
How do I change the language later?
Settings → Language & Region, then log out and in.
Is my data sent anywhere?
Only what's listed in Security and privacy → What goes online by itself.
