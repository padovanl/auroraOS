Use this guide to choose one of Aurora's backgrounds or add your own. The complete reference, including daylight series and slideshows, is in Appearance and backgrounds.

Choose an included still image

  1. Open Settings with Super+I, then select Appearance.
  2. Under Background, select Static image.
  3. Browse the thumbnails or use Search wallpapers. The gallery scrolls within the page.
  4. Click the image you want. It applies immediately; there is no separate Apply button.
Show the static wallpaper gallery

Choose an animated wallpaper

  1. On the same page, select Animated wallpaper.
  2. Click a video thumbnail. The preview and background use the selected video.
  3. Keep Play animation on for motion. Turn it off to pause on the video's poster while retaining your selection.

A Daylight series is a set of still pictures that changes with the sun. An Animated wallpaper is a looping video. Choose Static image if you want a picture that stays still.

Import your own photo or video

  1. Click Load a File… beside the current wallpaper preview.
  2. Select a readable picture or video. Pictures include PNG, JPEG and WebP; videos include MP4, WebM, M4V and MOV.
  3. Wait for the Wallpaper added message. Aurora copies the file into your personal wallpaper collection, chooses the matching type and applies it.

Your imported files appear alongside the included backgrounds. Preferences belong to your account; choosing a wallpaper does not change another user's selection.

Make a place for your documents

  1. Open Files with Super+E and select Documents in the sidebar.
  2. Right-click empty space and choose New Folder…. Enter a name and create it.
  3. Double-click the folder to open it. Right-click a folder and choose Add to Sidebar if you use it often.

Copy or move files

  1. Select the files. Hold Ctrl to select individual items or Shift to select a range.
  2. Use Ctrl+C to copy, or Ctrl+X to move.
  3. Open the destination folder, then press Ctrl+V.
  4. Watch the progress. The top-bar list icon opens the activity center; it keeps running work above completed work.

Alternatively, drag the selection onto a folder or sidebar place. Hold Ctrl to request a copy or Shift to request a move. Wait for completion before unplugging a drive, then use its eject button in the sidebar.

Recover a mistake

  • For supported file operations, use Ctrl+Z to undo; Ctrl+Shift+Z redoes the operation.
  • For a file sent to the Trash, select Trash in the sidebar, right-click the file and choose Restore.
  • Delete Permanently and Empty Trash remove files permanently. Use ordinary Trash deletion when you want the option to restore.

See Files for tabs, archives, search, network folders and keyboard shortcuts.

Create another account

  1. Open Settings → Users. Scroll down to Other Users.
  2. Click the + button beside Other Users.
  3. Enter a full name, username and password. The suggested username can be edited; it stays unchanged when you subsequently edit the full name.
  4. Choose whether the new account is an administrator. Use a standard account for ordinary work; administrators can authorize system changes.
  5. Click Add and complete the administrator authorization. The page becomes available again when the operation finishes or is cancelled.
Show account and login controls

Log in as another user

  1. Save your work, then use the Aurora menu → Log Out.
  2. At the login screen, select the other account and enter its password.
  3. If a session selector is available, choose Aurora or Aurora Compatibility, then log in.

Accounts have separate files, preferences, clipboards and activity journals. Aurora currently provides this logout-and-login flow rather than a graphical fast-user-switching control. Two simultaneous graphical desktops for the same account are unsupported; use distinct accounts for concurrent graphical desktops.

Automatic login and removing accounts

Log in automatically skips the login screen at boot for the chosen account. Turn it off if you want to choose a user each time. See Login screen for the keyring behavior.

Removing an account deletes its home folder. Back up its files first and log it out before removing it; the active account cannot be removed. See Security and privacy for account protection and administrator prompts.
